# 模板 C：数学公式

适合：高度抽象的数学、物理公式，算法和 AI 原理讲解。
特点：推导一步一步出现，公式和图形联动，逻辑清楚。

## 1. 规格定尺寸

- 比例：用户所选（16:9 为 1920×1080，9:16 为 1080×1920，1:1 为 1080×1080）
- 帧率：30fps
- 时长：以配音时长为准，片尾留 0.5 秒收尾
- 输出：MP4（H.264），音频 AAC

## 2. 风格定长相

- 以参考图的配色为准；参考图没有明确倾向时，默认用 3Blue1Brown 式深色风格：背景近黑 #1C1C1C，公式白色 #F5F5F5，变量分别用蓝 #58C4DD、黄 #FFFF00、绿 #83C167、红 #FC6255 区分
- 同一个变量在整条视频里始终用同一种颜色
- 公式用 LaTeX 排版，清晰锐利
- 坐标系、函数曲线用细线，网格线低透明度
- 画面极简，不加装饰元素

## 3. 节奏定时间

- 每一步推导 3～6 秒，讲到哪一项，哪一项才出现或高亮
- 关键结论出现后停留至少 1.5 秒
- 不要一次性把整条公式摆出来

## 4. 画面定动作

- 公式逐项写出（从左到右淡入或描写）
- 变形推导：相同的项在两步之间平滑移动到新位置（公式变形动画），新出现的项淡入，被消掉的项淡出
- 讲到某个变量时，给它加框或放大高亮
- 公式和图形联动：参数变化时，图形同步变化（例如改变斜率 k，直线跟着转）
- 几何证明：图形分块移动、旋转、拼合
- 最终结论加一个框，放在画面中央

## 5. 音乐定情绪

- 背景音乐：安静的氛围钢琴或 Lo-fi，不抢注意力，60～80 BPM
- 音效：公式出现用很轻的"叮"，推导完成用一个柔和的上扬提示音，其余时候尽量安静
- 背景音乐音量为人声的 10%～15%，结尾 1 秒淡出

## 6. 工具定实现

- Remotion：负责时间轴、字幕（可选）和最终合成渲染
- KaTeX（或 MathJax）：渲染 LaTeX 公式；需要逐项动画时，把公式拆成多个部分分别渲染定位
- SVG / Canvas：绘制坐标系、函数曲线和几何图形，曲线用 stroke-dashoffset 生长
- Manim（可选）：环境里已安装 Python 和 Manim 时，复杂的公式变形镜头可以用 Manim 单独渲染成视频片段，再放进 Remotion 合成
- 所有动画用 Remotion 的 useCurrentFrame 和 interpolate / spring 驱动

## 7. 交付定检查

- 逐条核对公式，确保数学上正确，上下标、符号没有错
- 同一个变量颜色前后一致
- 公式字号在手机上也能看清（16:9 时正文公式不小于 48px）
- 按 SKILL.md 中的交付前检查清单逐项确认
