# 模板 F：美术馆

适合：名画赏析、艺术史、文物、设计史、建筑、摄影作品、博物馆藏品。总之是"一件作品值得细看"的内容。
特点：黑色展厅，作品本身就是舞台。金属玻璃镜片在画上移动、局部放大，排版优雅克制，像在美术馆里跟着讲解员看画。

**本模板配有现成组件库：`components/gallery/`。先读它的 README.md，复用液态玻璃画布和文字组件，不要从零写。**

## 1. 规格定尺寸

- 比例：用户所选。竖屏时轮盘半径和档案卡位置需要重排
- 帧率：30fps；时长以配音为准
- 渲染必须开 WebGL：`--gl=swangle`

## 2. 风格定长相

- 底色近黑 #0E0E03，画作打光偏暗，四周暗角，加细颗粒
- 强调色：铜 #D9A273（镜框、强调词、分隔线）；正文米白 #F2EDE4；次要灰 #A39A8B
- 字体：中文宋体（Noto Serif CJK）+ 外文意大利斜体（Instrument Serif Italic）+ 数据等宽小字（JetBrains Mono）
- 文字直接排在暗处（画外或压暗的画上），不加纸片、底框；靠字号、字距和阴影保证可读
- 画面克制：一屏只讲一件事，留白多

## 3. 节奏定时间

- 推荐四段式：选择（5～6 秒）→ 讲解档案（6～7 秒）→ 细节 ×2～3（每个 4～5 秒）→ 结语（5～6 秒）
- 镜头推拉 1.2～1.5 秒，放大镜落下 1 秒（弹簧），文字在镜头停稳后再出现
- 细节编号 `01 / 03` 让观众知道还有几个

## 4. 画面定动作

- 开场：作品轮盘（`makeWheel`），同一作者或同一主题的 3～5 件作品，旋转后停在主角上，经过中心的作品名闪现
- 讲解：中心镜片渗满全屏（半径从 178 涨到 1250），画右移，左侧出现档案卡（`ArtworkCard`）
- 细节：`focus` 推镜到局部 → `magnifier` 落下放大 → 下一个细节时镜片滑过去（带液态拉伸）
- 对比：两个镜片加 `CompareMarks`（左右、高低、前后、真伪）
- 结语：画作缩回镜片，轮盘转一圈，标题加一句金句
- **所有坐标先用 `uv_grid.py` 校准**

## 5. 音乐定情绪

- 背景音乐：古典钢琴、弦乐四重奏、氛围古典，安静高级
- 音效：轮盘每过一格配轻"嗒"（`tickFrames` 自动算）；镜片落下配柔和的玻璃声或低频"咚"；镜头推拉配轻柔的风声
- 优先使用用户本地素材库；混音和三版本导出用 `common/scripts/mix_audio.py`

## 6. 工具定实现

- Remotion + 组件库 `components/gallery/`（WebGL 液态玻璃画布 + React 文字层）
- 画作：维基共享资源公版高清图（`vintage-archive/scripts/fetch_commons.py`），附 `sources.txt`
- 配音和对齐：`common/scripts/tts.py`、`align.py`
- 完整示例：`components/gallery/example/MonaLisa.tsx`

## 7. 交付定检查

- 每个放大镜都对准了口播说的那个细节（截图核对，不要只信坐标）
- 镜片移动、轮盘旋转这类连续动作，抽 8 帧连续画面检查，确认没有跳变
- 画作没有出现黑块（黑块说明纹理加载失败，检查文件名和 `--gl` 参数）
- 作品信息（作者、年代、材质、尺寸、收藏地）都要列出依据，让用户确认
- 按 SKILL.md 中的交付前检查清单逐项确认

## 和复古档案模板混用

两套组件可以互相借用：

- **复古档案借放大镜**：用 `vintage-archive` 里的 `Magnifier`（DOM 版、黄铜框，不需要 WebGL）
- **美术馆借包装件**：可以借印章、红圈、铭牌，但要换成铜色，克制使用
- **镜框统一**：`GalleryCanvas` 传 `ring="#B8893B"`，镜框就变成黄铜色，和复古档案一致
