# 模板 A：3D 数据

适合：有硬数据的内容，例如数据新闻、科技产品发布、行业报告、财报解读。
特点：最擅长做有空间感、有冲击力的大画面。

## 1. 规格定尺寸

- 比例：用户所选（16:9 为 1920×1080，9:16 为 1080×1920，1:1 为 1080×1080）
- 帧率：30fps
- 时长：以配音时长为准，片尾留 0.5 秒收尾
- 输出：MP4（H.264），音频 AAC

## 2. 风格定长相

- 以参考图的配色和质感为准；参考图没有明确倾向时，默认用深色科技风：深蓝黑背景（#050B1A → #0B1E3F 渐变），主色青蓝 #2EC5FF，强调色橙 #FF8A3D
- 3D 物体带柔和的体积光、轮廓光和反射，材质偏金属或半透明玻璃
- 背景加轻微的粒子、网格地面或景深虚化，营造空间感
- 数字用粗体无衬线字体，大字号，关键数字加发光
- 画面元素少而大，一个镜头只突出一个数据

## 3. 节奏定时间

- 每个镜头 2～4 秒，跟着口播句子切换
- 开场 1 秒内必须出现第一个视觉冲击（大数字、地球、物体飞入）
- 数字出现时做滚动计数，0.6～1.0 秒滚到目标值
- 镜头切换用相机推拉、穿梭、旋转过渡，避免硬切

## 4. 画面定动作

- 相机始终有缓慢运动（推近、环绕、平移），画面不能完全静止
- 柱状图：柱子从地面依次升起，带弹性缓动
- 折线图：线条从左到右生长，关键点亮起并弹出数值
- 占比：3D 饼图或环形图分块旋转展开
- 地域数据：3D 地球旋转到对应区域，标记点升起光柱
- 对比：两个物体左右并列，按数值比例缩放
- 口播里提到的每个数字、关键词都要在画面上出现

## 5. 音乐定情绪

- 背景音乐：科技感电子乐，节奏稳定有推进感，90～120 BPM
- 音效：数字滚动用轻快的"嘀嗒"声，物体落地用低沉的"咚"，镜头穿梭用"嗖"的风声，关键数据出现时加一个"叮"
- 背景音乐音量为人声的 15%～25%，结尾 1 秒淡出

## 6. 工具定实现

- Remotion：负责时间轴、字幕（可选）、2D 文字层和最终合成渲染
- Three.js（@remotion/three + @react-three/fiber）：负责 3D 场景、相机运动和数据图形
- Blender（可选）：需要复杂模型（如精细地球、产品模型）时，用 Blender 建模导出 glb，再在 Three.js 中加载；没有 Blender 时，用 Three.js 自带几何体组合实现
- 所有动画用 Remotion 的 useCurrentFrame 和 interpolate / spring 驱动，不要用 setTimeout 或 CSS 动画

**参考实现：** `components/3d-data/README.md` + `reference/scene.js`（SpaceX 财报快讯，已出片）。3D 文字、发光轨迹、网格地面、全息体、遮罩转场、Bloom 都已经写好，优先复用。

## 7. 交付定检查

- 检查每个 3D 镜头的首帧和末帧，确认没有黑屏、模型没有穿模或出画
- 确认所有数字数值和口播一致
- 3D 场景渲染慢时，先降低粒子数量和阴影质量，不要删镜头
- 按 SKILL.md 中的交付前检查清单逐项确认
