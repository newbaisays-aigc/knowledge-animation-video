# 模板 B：手绘涂鸦

适合：没有太多硬数据、偏观点和故事的内容，例如历史人文、社会现象、新闻解读、读书笔记、心理学概念。
特点：亲和、有温度，像有人边讲边在纸上画。

## 1. 规格定尺寸

- 比例：用户所选（16:9 为 1920×1080，9:16 为 1080×1920，1:1 为 1080×1080）
- 帧率：30fps
- 时长：以配音时长为准，片尾留 0.5 秒收尾
- 输出：MP4（H.264），音频 AAC

## 2. 风格定长相

- 以参考图的配色和笔触为准；参考图没有明确倾向时，默认用米白纸张背景（#FAF6EC，带轻微纸纹），黑色墨线 #222，点缀色 1～2 个（如暖橙 #F28C38、天蓝 #4A9FD8）
- 线条有手绘的轻微抖动和粗细变化，不要完美的几何线
- 上色像马克笔：不完全填满轮廓，留出笔触痕迹
- 文字用手写感字体（如站酷快乐体、ZCOOL KuaiLe 或类似的手写体），关键词加圈、下划线或箭头
- 人物用简笔小人，表情夸张清楚

## 3. 节奏定时间

- 每个镜头 3～5 秒，比 3D 模板稍慢，给观众看画的时间
- 画面跟着口播"边讲边画"，讲到哪个词，对应的图就在那时画出来
- 一个观点讲完再擦掉或翻页，进入下一个

## 4. 画面定动作

- 核心动作是"描线生长"：用 SVG 路径的 stroke-dashoffset 让线条按笔画顺序画出来，每个图形 0.5～1.2 秒
- 线条画完后再上色，上色用遮罩从一侧刷过去
- 可选：一只手或一支笔跟着描线位置移动
- 概念关系用箭头连接，箭头最后画出
- 转场：翻纸、擦除、镜头平移到画布的下一块区域
- 用比喻把抽象概念画成具体物件（例如"信息茧房"画成一个被丝包住的小人）

## 5. 音乐定情绪

- 背景音乐：轻快的原声吉他、尤克里里或钢琴，温暖不吵，70～100 BPM
- 音效：画线时用轻微的笔尖摩擦声，翻页用纸张翻动声，强调时用"啵"一类轻巧的提示音
- 背景音乐音量为人声的 15%～20%，结尾 1 秒淡出

## 6. 工具定实现

- Remotion：负责时间轴、字幕（可选）和最终合成渲染
- SVG + stroke-dashoffset：实现描线动画，所有图形用 SVG 路径绘制
- roughjs（可选）：给几何图形加手绘抖动效果
- 纸张纹理用 CSS 噪点或一张低透明度的纹理图叠加
- 所有动画用 Remotion 的 useCurrentFrame 和 interpolate 驱动

## 7. 交付定检查

- 检查每条线是否都完整画完，没有画到一半就切镜头
- 手写字体能正常显示中文，没有出现方框乱码
- 画面元素不要太满，留白至少 30%
- 按 SKILL.md 中的交付前检查清单逐项确认
